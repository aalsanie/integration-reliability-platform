# Integration Reliability Platform

A backend platform for receiving, processing, delivering, retrying, and reconciling events exchanged with external systems.

## Current Status

The project is under active development.

The first milestone covers:

* integration connection management
* inbound event ingestion
* PostgreSQL persistence
* schema migrations
* duplicate-event protection

## Technology

* Java
* Spring Boot
* PostgreSQL
* Flyway
* Docker Compose
* Testcontainers

## Running Locally

Local setup instructions will be added as the first development milestone is completed.
